# Обоснование ML (модуль Д)

## Алгоритм: Facebook Prophet

**Задача:** прогноз средней скорости на горизонте 30 мин по рядам batch-агрегатов (`gold_traffic_aggregates`).

**Почему Prophet:**
- Ряды с **получасовой** дискретизацией и суточной сезонностью (утренний/вечерний пик).
- Устойчивость к пропускам окон (дообучение после late data в Silver).
- Интервалы `yhat_lower` / `yhat_upper` для Metabase.
- Быстрое обучение на площадке без GPU (в отличие от LSTM).

**Ограничения:** при <10 точек на пару (camera, direction) прогноз пропускается — явно в логах.

**Метрики:** hold-out 24 ч — MAE, RMSE в `gold_predictions`.

**Альтернативы:** ARIMA — хуже с множеством рядов; XGBoost — нужны лаги и признаки, дольше на 3 часа модуля.

## Встраивание

DAG `ml_speed_forecast`, schedule `*/30`, после накопления batch-витрин.
