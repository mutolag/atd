# Требования к системе (модуль А)

## Функциональные

| ID | Требование |
|----|------------|
| F1 | Детекция ТС из видеопотока, тип, направление, трекинг |
| F2 | Потоковые метрики и опасные ситуации в реальном времени |
| F3 | Batch-агрегаты и пересчёт каждые 30 мин по камере и направлению |
| F4 | Прогноз средней скорости на 30 мин вперёд |
| F5 | Дашборд: realtime / batch / forecast / инциденты с фильтрами |
| F6 | Сохранение кадров с объектами в объектное хранилище |

## Нефункциональные

| ID | Требование |
|----|------------|
| NF1 | Нет потери данных при кратковременной недоступности БД |
| NF2 | Подключение новых камер без смены архитектуры |
| NF3 | Аномалии потока и batch — в логах, не в витринах |
| NF4 | Учёт опоздавших событий в batch (watermark) |
| NF5 | Масштабирование потока через Kafka partitions |
